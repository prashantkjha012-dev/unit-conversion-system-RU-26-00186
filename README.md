# Unit Conversion System

## Project Overview
The Unit Conversion System is a Python 3-based application that converts values between different units through a simple menu-driven interface.

It supports four types of conversions:
1. Length
2. Weight
3. Temperature
4. Time

## Project Details
- Project Title: Unit Conversion System
- PS No.: 5
- Programming Language: Python 3
- Course: Bachelor of Technology (B.Tech)
- Branch: Computer Science and Engineering
- University: Rungta International Skills University

## Objectives
- To develop a simple and user-friendly unit converter.
- To convert values between different measurement units.
- To understand Python functions, operators, and conditional statements.
- To validate user input and handle invalid choices.
- To display results rounded to 2 decimal places.

## Features
- Length Conversion
- Weight Conversion
- Temperature Conversion
- Time Conversion
- Menu-driven interface
- Input validation
- Error handling
- Results rounded to 2 decimal places
